# Margonem Crimson — Hebrehoth

Motyw Tampermonkey dla Margonem. Używa wyłącznie dwóch dostarczonych grafik: `hebrehoth-smokoludzie.gif` po bokach nagłówka i `archdemon.gif` jako centralnego emblematu. Nie zmienia sprite’ów przedmiotów, postaci ani NPC.

## Instalacja po publikacji na GitHub

W Tampermonkey otwórz ten adres i kliknij **Zainstaluj**:

`https://raw.githubusercontent.com/bSlawek-03/Margonem-Crimson/main/Margonem-Crimson.user.js`

Tampermonkey będzie następnie sprawdzał aktualizacje z tego samego repozytorium.

## Struktura

- `Margonem-Crimson.user.js` — skrypt instalowany w Tampermonkey.
- `assets/hebrehoth-smokoludzie.gif` — grafika po bokach nagłówka.
- `assets/archdemon.gif` — grafika emblematu.
